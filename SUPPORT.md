# Getting help

**Something's wrong.** [Report a bug](https://github.com/neogentrics/rt-author-desk/issues/new?template=bug_report.yml). Include your
version (it's in the name of the file you installed) and the steps that cause it. A screenshot helps, but please don't
include a real sales report, account number or login.

**You have an idea.** [Suggest a feature](https://github.com/neogentrics/rt-author-desk/issues/new?template=feature_request.yml). Check the
[roadmap](ROADMAP.md) first, since it may already be planned.

**It's a security problem.** Please don't open a public issue. Follow [SECURITY.md](SECURITY.md).

RT Author Desk is free, and support is on a best-effort basis.
